This update changed the `/api/v0/users` endpoints to return `403` for API keys, apart from the endpoints that look up a member of your *Organization*.

## Fixes

* Fixed an issue where a request to the `/api/v0/users` endpoints with an API key returned a `500` error or an unexpected response. These endpoints act on the signed-in user, so they now return `403` for an API key. `GET /api/v0/users/{user_identifier}` and `GET /api/v0/users/{user_identifier}/avatar` still accept an API key, allowing you to look up members of your *Organization*.
