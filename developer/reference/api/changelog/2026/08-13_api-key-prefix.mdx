This update changed new *API Keys* to start with a CloudCannon-specific prefix, which lets secret scanning tools recognize them.

## Changed

* Changed new *API Keys* to start with `cca_`, so secret scanning tools can recognize a CloudCannon *API Key* that has been committed to a repository. *API Keys* created before this change start with `cc_` and still work.
