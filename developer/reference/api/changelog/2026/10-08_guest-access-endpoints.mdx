This update added endpoints and fields for *Guest Access*, which replaced *Client Sharing*, and deprecated the *Client Sharing* endpoints and fields.

## Added

* Added the `guest-access` and `guest-password` endpoints, allowing you to manage *Guest Access* for a *Site*.
* Added the `guest_` fields to *Site* responses, which replace the `client_` fields.

## Deprecated

* Deprecated the `client-sharing` and `client-password` endpoints and the `client_` fields on a *Site*. They still work, but the `guest-access` and `guest-password` endpoints and the `guest_` fields replace them.
