This update made every field optional on the *Inbox* and *Inbox Target* update endpoints, added a field for allowing file uploads, and fixed captcha provider validation.

## Added

* Added the `allow_uploads` field to the fields you can set on an *Inbox*.

## Changed

* Changed the *Inbox* and *Inbox Target* update endpoints so that every field is optional, allowing you to send only the fields you want to change.

## Removed

* Removed the `monthly_quota` field from the fields you can set on an *Inbox*.

## Fixes

* Fixed an issue where an *Inbox* accepted an unrecognized captcha provider, which then never ran.
