Error pages in the CloudCannon app, on hosted Sites, and in the Visual Editor preview show an error code, such as `FS-402-02`. Most of these pages also show a Reference and the time the error happened. The error code tells you which situation caused the error, and this page explains what each code means, who sees it, and what you can do about it.

Error pages in the CloudCannon app, and preview error pages that open in a browser tab of their own, link the error code to its entry on this page. Error pages on a hosted <comp.GlossaryTerm term="/user/glossary/s/site.yml">Site</comp.GlossaryTerm>, and error pages shown inside the preview in the <comp.GlossaryTerm term="/user/glossary/v/visual-editor.yml">Visual Editor</comp.GlossaryTerm>, show the error code as plain text.

<comp.Notice info_type="info">
  If you see an error on a website that you don't manage, contact the website's owner. Only the owner can change the website's settings.
</comp.Notice>

## How to read an error code

Each error code has three parts. For example, in `FS-402-02`:

* `FS` is the system that showed the error page.
* `402` is the HTTP status code of the response.
* `02` is the case number, which identifies the exact situation that caused the error.

The system prefix tells you where the error happened:

* `APP` is the CloudCannon app at app.cloudcannon.com.
* `FS` and `RT` are the servers that host your *Site*.
* `VC` and `NG` are CloudCannon's hosting edge, which filters traffic before it reaches the servers that host your *Site*.
* `PX` is the preview of your *Site* that the *Visual Editor* loads.

Two case numbers have a fixed meaning:

* `00` is an error without a more specific code. For example, `FS-403-00` is a request the servers that host your *Site* refused for a reason that has no code of its own.
* `10` on a `PX` code is a page shown inside the preview in the *Visual Editor*, rather than in a browser tab of its own.

Several error codes can share a page title. For example, every `402` page reads *This site is currently unavailable*, and the case number tells you which situation caused it.

## Reference and time

Below the error code, most error pages show a Reference and the time of the error in UTC. The Reference identifies your request, so our support team can find exactly what happened.

Some pages show only the error code. These are pages that many visitors can see at once, such as *Page not found* and *This site is currently unavailable* on a hosted *Site*, and the pages CloudCannon shows while the app is unavailable.

If you contact our <a href="https://cloudcannon.com/support/">support team</a> about an error, include the error code, the Reference, and the time exactly as they appear on the page.

You see these pages in the CloudCannon app while you are logged in or logging in. People who open a *Site* through a <comp.GlossaryTerm term="/user/glossary/c/client-sharing.yml">Client Sharing</comp.GlossaryTerm> link can also see [`APP-403-04`](#app-403-04) and [`APP-404-02`](#app-404-02) without logging in.

These pages appear only in a web browser. Scripts and API clients that don't ask for an HTML page receive a plain response without an error code instead.

## Hosting edge (VC and NG)

CloudCannon's hosting edge filters traffic before it reaches the servers that host your *Site*. Most of these pages protect your *Site* from automated traffic, such as scanners, crawlers, and spam bots. Visitors see these pages on your *Site's* *Custom Domain* or *Testing Domain*.

If a real visitor sees one of these pages when they shouldn't, contact our <a href="https://cloudcannon.com/support/">support team</a> with the error code, Reference, and time from the page.
