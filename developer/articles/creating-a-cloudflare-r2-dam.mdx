Cloudflare R2 is an inexpensive cloud storage service built to be compatible with Amazon's S3 interface. 

If you don't already have a Cloudflare account, you can <a href="https://dash.cloudflare.com/sign-up" target="_blank" rel="noopener noreferrer">sign up here</a> and follow the steps below to create an R2 bucket and connect it to CloudCannon.

### Create your R2 bucket

Sign in to the <a href="https://dash.cloudflare.com/" target="_blank" rel="noopener noreferrer">Cloudflare dashboard</a> and open the R2 settings from the sidebar.

Use the "Create Bucket" button to create a new bucket, or select an existing bucket to configure it.

<comp.DocsImage path="assets/external_screenshots/create-r2-bucket.png" alt="A screenshot of the R2 Overview page in the Cloudflare dashboard shows a list of buckets, a bucket name search field, and the Create bucket button in the top right." title="The Cloudflare R2 Overview page with the Create bucket button" type="screenshot" />

Choose a name for your bucket. This can be anything and will be displayed as the name of the DAM in CloudCannon.

Optionally, you can select a region for your bucket, if you don't want it to be autoselected.

Click "Create bucket" to finish and create the bucket.

<comp.DocsImage path="assets/external_screenshots/r2-initial-bucket-settings.png" alt="A screenshot of the Create a bucket page in Cloudflare shows a Bucket name field, the Automatic location option with an optional location hint, restricted access by default, and the Create bucket button." title="The Cloudflare Create a bucket page" type="screenshot" />

### Provide access through a custom domain

Navigate to your bucket in the R2 console, and switch to the "Settings" tab.

In the "Public access" section, you can add a custom domain where your assets will be served.

You can read more about making the contents of your bucket publically accessible here <a href="https://developers.cloudflare.com/r2/buckets/public-buckets/" target="_blank" rel="noopener noreferrer">in the Cloudflare documentation</a>.

<comp.DocsImage path="assets/external_screenshots/r2-bucket-public-access.png" alt="A screenshot of the Settings tab for an R2 bucket in Cloudflare shows the Bucket Details section and the Public access section, where the Add a custom domain form has a Domain field and a Continue button." title="The Public access section of the R2 bucket Settings tab" type="screenshot" />


### Configure CORS policies

You will need to configure your CORS policies to allow CloudCannon to interact with your bucket. In the "Settings" tab for your bucket in Cloudflare, click the "Edit CORS policy" button.

Minimally, you need to allow the GET and PUT methods, and the Content-Type header for https://app.cloudcannon.com.

<comp.DocsImage path="assets/external_screenshots/r2-bucket-cors-policy.png" alt="A screenshot of the Edit CORS policy page in Cloudflare shows a JSON policy allowing the origin https://app.cloudcannon.com, the GET and PUT methods, and the Content-Type header, with a Save button." title="The Cloudflare Edit CORS policy page" type="screenshot" />


### Create an API token

You will also need to provide an API token to allow CloudCannon to access your bucket. Navigate back to the Overview page for R2 on your account, by clicking "R2 > Overview" in the sidebar. 

Note down your account ID, which you'll need to copy into your CloudCannon settings later on.

Click "Manage R2 API tokens" in the top-right, and create a new API token. Copy the secret to somewhere safe.

<comp.DocsImage path="assets/external_screenshots/r2-manage-api-token.png" alt="A screenshot of the Cloudflare R2 Overview page shows the Manage R2 API Tokens link and the Account ID field in the right-hand column, next to the Buckets list." title="The Cloudflare R2 Overview page with the Account ID" type="screenshot" />

### Connect your DAM to CloudCannon

You should now have everything you need to connect CloudCannon with your R2 DAM.

Navigate to the Assets section of your Organization settings, and use the menu to authenticate a new Cloudflare R2 DAM.

<comp.DocShot docshot_key="CloudCannon-Documentation-DAM-CloudflareR2-Settings" title="The form for authenticating an R2 DAM" alt="A screenshot of the Authorize new DAM page in Org Settings shows Cloudflare R2 selected as the DAM provider, with fields for Name, Base URL, Bucket Name, Region, and Endpoint." type="screenshot" />

Fill out the form as follows, then click "Authenticate" to finish.

* **DAM Provider**: Cloudflare R2.
* **Name**: This is the name you will see for your DAM in CloudCannon.
* **Base URL**: the domain name of the custom domain you configured earlier, where all your DAM assets are accessible.
* **Region**: This can be set to `auto`.
* **Endpoint**: you can copy the endpoint from your bucket settings, directly below the name of the bucket. It will look something like `https://[your-account-id].r2.cloudflarestorage.com`, and should not include anything after the ".com".
* **Access Key**: this is your Cloudflare account ID.
* **Access Secret**: this is the API token you saved earlier.

### Extra options

In your site settings, you can click the context menu on your linked DAM and select **Settings** to configure some extra site-level options.

The **Extra Prefix** option prepends a specified string to all asset paths when browsing and uploading assets. This is useful if you want to ensure that your site can only ever touch a specific folder in your DAM.
