You can forward the submissions an <comp.GlossaryTerm term="/user/glossary/i/inbox.yml">Inbox</comp.GlossaryTerm> receives to a Make scenario, using a custom webhook and a *Make* target. Make was formerly called Integromat, and existing Integromat webhooks keep working.

Create the webhook in Make first, because the *Target* field needs its URL.

To create a Make webhook:

1. Sign in to Make, or <a href="https://www.make.com/en/register" target="_blank" rel="noopener noreferrer">create a Make account</a>.
2. In the Make console, open the *Scenarios* menu in the sidebar and click the *Create a new scenario* button.
3. Add a *Webhooks* module and select *Custom webhook* as its type.
4. When prompted to select a webhook, click the *Add* button and create a new webhook.
5. Click the *Copy address to clipboard* button. You can find the URL again from the *Webhooks* menu in the Make sidebar.
6. Add any other modules you want, then save your scenario.

<comp.DocsImage path="assets/external_screenshots/make-scenarios-add.png" alt="A screenshot of the Make console shows the scenario creation screen with a Webhooks module added." title="The Make scenario creation screen" type="screenshot" />

Now add the target in CloudCannon. Set the *Type* dropdown to *Make* and paste the webhook URL into the *Target* field. For the full steps, please read our documentation on [adding a target to an Inbox](/documentation/developer-articles/add-a-target-to-an-inbox/).

<comp.DocShot docshot_key="CloudCannon-Documentation-Org-Settings-Forms-Add-Target-Make-Modal" alt="A screenshot of the Add target modal shows the Type dropdown set to Make and a Make webhook URL in the Target field." title="The Add target modal" type="screenshot" />

CloudCannon will run your scenario with the data from each new submission.
