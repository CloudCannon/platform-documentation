<comp.Notice info_type="permissions">
  **Permissions required**

  Members of the *Owners* and *Developers* [Default Permission Groups](/documentation/user-articles/what-are-default-permission-groups/), or [Custom Permission Groups](/documentation/developer-articles/what-are-custom-permission-groups/) with the `org:settings:inbox:write` permission, can add a target to an *Inbox*.
</comp.Notice>

A target tells CloudCannon where to forward the submissions an <comp.GlossaryTerm term="/user/glossary/i/inbox.yml">Inbox</comp.GlossaryTerm> receives. Every target has a type, which decides what goes in the *Target* field: an email address for the *Email* type, or a webhook URL for an external service. For more information, please read our documentation on [what an Inbox Target is](/documentation/developer-articles/what-is-an-inbox-target/).

Adding a target does not change how your forms submit. CloudCannon keeps storing every submission in the *Inbox* and forwards a copy to each target.

Set up the receiving end first, because the *Target* field needs a value from it. For instructions per type, please read our documentation on sending form submissions to [email](/documentation/developer-articles/send-form-submissions-to-email/), [Slack](/documentation/developer-articles/send-form-submissions-to-slack/), [Zapier](/documentation/developer-articles/send-form-submissions-to-zapier/), [IFTTT](/documentation/developer-articles/send-form-submissions-to-ifttt/), or [Make](/documentation/developer-articles/send-form-submissions-to-make/).

To add a target to an *Inbox*:

1. Navigate to the *Forms* page under *Org Settings*.
2. Select the *Inbox* you want to forward submissions from.
3. Open the *Targets* tab.
4. Click the *Add target* button.
5. Set the *Type* dropdown to the target type you want.
6. Enter the email address or webhook URL in the *Target* field.
7. Click the *Add target* button.

CloudCannon will add the target to your *Inbox* and start forwarding new submissions to it. An *Email* target does not receive submissions until you click the validation link CloudCannon sends to that address.

The number of targets you can add to an *Inbox* depends on your <comp.GlossaryTerm term="/user/glossary/s/subscription-plan.yml">Subscription Plan</comp.GlossaryTerm>. For more information, please read our documentation on [how Inbox limits work](/documentation/developer-articles/how-do-inbox-limits-work/).
