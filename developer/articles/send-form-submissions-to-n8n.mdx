You can forward the submissions an <comp.GlossaryTerm term="/user/glossary/i/inbox.yml">Inbox</comp.GlossaryTerm> receives to an n8n workflow, using a Webhook node and an *n8n Cloud* target.

An *n8n Cloud* target only accepts a URL on an n8n Cloud workspace host, in the form `<workspace>.app.n8n.cloud`. A self-hosted n8n instance is not accepted by this type, so use a *Custom webhook* target for one instead. For more information, please read our documentation on [sending form submissions to a custom webhook](/documentation/developer-articles/send-form-submissions-to-a-custom-webhook/).

Create the workflow in n8n first, because the *n8n webhook URL* field needs its production URL.

To get an n8n production webhook URL:

1. Sign in to n8n Cloud, or <a href="https://n8n.io/cloud/" target="_blank" rel="noopener noreferrer">create an n8n Cloud account</a>.
2. Open the workflow you want to receive submissions, or create a new one.
3. Add a *Webhook* node as the trigger for your workflow.
4. Click the *Production URL* button at the top of the node parameters, then copy the URL.
5. Publish your workflow, so n8n registers the production webhook.

n8n will start accepting requests at that production URL, and run your workflow for each one.

Now add the target in CloudCannon. Select *n8n Cloud* in the *Choose your target type* dropdown and paste the production URL into the *n8n webhook URL* field. For the full steps, please read our documentation on [adding a target to an Inbox](/documentation/developer-articles/add-a-target-to-an-inbox/).

<comp.DocShot docshot_key="CloudCannon-Documentation-Org-Settings-Forms-Add-Target-N8N-Modal" alt="A screenshot of the Add target modal shows n8n Cloud chosen as the target type and a production webhook URL in the n8n webhook URL field." title="The Add target modal" type="screenshot" />

CloudCannon will post each new submission to your Webhook node as JSON, and n8n will run the rest of your workflow with it.

For the *Spam protection* and *Links to attached files* options a target can carry, please read our documentation on [adding a target to an Inbox](/documentation/developer-articles/add-a-target-to-an-inbox/).
