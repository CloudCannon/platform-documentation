You can forward the submissions an <comp.GlossaryTerm term="/user/glossary/i/inbox.yml">Inbox</comp.GlossaryTerm> receives to an email address, using an *Email* target.

Set the *Type* dropdown to *Email* and enter the address in the *Target* field. For the full steps, please read our documentation on [adding a target to an Inbox](/documentation/developer-articles/add-a-target-to-an-inbox/).

<comp.DocShot docshot_key="CloudCannon-Documentation-Org-Settings-Forms-Add-Target-Email-Modal" alt="A screenshot of the Add target modal shows the Type dropdown set to Email and an email address in the Target field." title="The Add target modal" type="screenshot" />

CloudCannon will send a validation link to that address. An *Email* target does not receive submissions until you click that link, after which CloudCannon emails each new submission to it.

## Customize the email

Add these hidden fields to your form to control the email CloudCannon sends. The fields can be hidden or visible, depending on your requirements.

Use `_replyto` for the Reply-To header, so replies reach the visitor rather than a default CloudCannon address.

<comp.CodeBlock language="html" source="contact.html">
```
<label>
  Your Email Address
  <input type="text" name="_replyto">
</label>
```
</comp.CodeBlock>

Use `_subject` for the subject line.

<comp.CodeBlock language="html" source="contact.html">
```
<select name="_subject">
  <option>General Enquiry</option>
  <option>Quote Request</option>
  <option>Support</option>
</select>
```
</comp.CodeBlock>
