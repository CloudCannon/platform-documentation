You can forward the submissions an <comp.GlossaryTerm term="/user/glossary/i/inbox.yml">Inbox</comp.GlossaryTerm> receives to a Slack channel, using a Slack incoming webhook and a *Slack* target.

Create the webhook in Slack first, because the *Target* field needs its URL.

To create a Slack webhook:

1. In the Slack API console, click the *Create an app* button and select the *From Scratch* option.
2. Name your app, select your Slack workspace, then click the *Create App* button.
3. Under the *Add features and functionality* heading, click *Incoming Webhooks*.
4. Turn the *Activate Incoming Webhooks* toggle on, then click the *Add New Webhook to Workspace* button.
5. Select the Slack channel you want to forward submissions to, then click the *Allow* button.
6. Copy the webhook URL. You can find it again from the *Incoming Webhooks* menu in the Slack sidebar.

<comp.DocsImage path="assets/external_screenshots/api-slack-com-apps-webhooks.png" alt="A screenshot of the Slack API console shows the Incoming Webhooks page with a webhook URL for a channel." title="The Slack Incoming Webhooks console" type="screenshot" />

Now add the target in CloudCannon. Set the *Type* dropdown to *Slack* and paste the webhook URL into the *Target* field. For the full steps, please read our documentation on [adding a target to an Inbox](/documentation/developer-articles/add-a-target-to-an-inbox/).

<comp.DocShot docshot_key="CloudCannon-Documentation-Org-Settings-Forms-Add-Target-Slack-Modal" alt="A screenshot of the Add target modal shows the Type dropdown set to Slack and a Slack webhook URL in the Target field." title="The Add target modal" type="screenshot" />

CloudCannon will forward each new submission to that Slack channel. For the payload Slack accepts, please read the <a href="https://api.slack.com/reference/messaging/payload" target="_blank" rel="noopener noreferrer">Slack message payload reference</a>.
