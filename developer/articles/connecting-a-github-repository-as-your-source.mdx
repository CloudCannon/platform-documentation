Connecting a GitHub *Git Repository* to your *Site* allows you to work on your website files locally and sync your changes to CloudCannon. CloudCannon also syncs file changes you make in CloudCannon back to GitHub.

To connect a *Git Repository* on GitHub to your *Site*:

1. Navigate to the *Syncing* page under *Site Settings*.
2. Select the *GitHub repository* option from the provider dropdown.
3. Click the *Authorize* button.

CloudCannon will redirect you to GitHub.

<comp.DocShot docshot_key="CloudCannon-Documentation-Site-Settings-Syncing-Select-GitHub-No-Authorization" alt="A screenshot of the Syncing page under Site Settings shows the GitHub repository option selected and an Authorize button." title="The Syncing page with GitHub selected" type="screenshot"/>

To give CloudCannon access to your GitHub account:

1. Enter your GitHub credentials to sign in.
2. Click the *Authorize CloudCannon* button.

If you haven't installed the CloudCannon GitHub App yet, GitHub will open the page for installing it. Otherwise, GitHub will redirect you back to the *Syncing* page.

<comp.DocsImage path="assets/external_screenshots/files-source-syncing-github-authentication.png" alt="The GitHub sign-in page, asking you to sign in to GitHub to continue to CloudCannon." title="The GitHub sign-in page" type="screenshot"/>

<comp.DocsImage path="assets/external_screenshots/files-source-syncing-github-authorisation.png" alt="The GitHub authorization page listing the permissions CloudCannon requests, with an Authorize CloudCannon button." title="The GitHub authorization page" type="screenshot"/>

To install the CloudCannon GitHub App:

1. Choose whether to install the CloudCannon GitHub App on your personal GitHub account or on your GitHub organization.
2. Select the *All repositories* option or the *Only select repositories* option.
3. Click the *Install* button.

GitHub will redirect you back to the *Syncing* page, where you can select the *Git Repository* to connect.

<comp.DocsImage path="assets/external_screenshots/files-source-syncing-github-installing.png" alt="The Install CloudCannon page on GitHub, with options to grant access to all repositories or only select repositories and an Install button." title="The Install CloudCannon page on GitHub" type="screenshot"/>

<comp.Notice info_type="important">
  When you click the *Backup and Sync* button, CloudCannon will replace any existing files on your *Site* with the contents of the selected *Git Repository*. To cancel the process, exit the page instead.
</comp.Notice>

To connect your *Git Repository* and branch:

1. Select your *Git Repository* from the *Repository* dropdown.
2. Choose the *Use an existing branch* option or the *Create a new branch* option under the *Branch Setup* heading.
3. Pick your branch from the *Branch* dropdown. If you are creating a new branch, pick the branch to copy from the *Source branch* dropdown and enter a name in the *New branch name* field.
4. Click the *Backup and Sync* button.

CloudCannon will connect your *Site* to your GitHub *Git Repository*. CloudCannon pulls in changes you push to your *Git Repository*, and automatically commits and pushes any changes you make in CloudCannon.

## Change which Git Repositories CloudCannon can access

If your *Git Repository* does not appear in the *Repository* dropdown, the CloudCannon GitHub App may not have access to it.

To change which *Git Repositories* the GitHub App can access:

1. Click the *Manage access* link below the *Repository* dropdown. CloudCannon will open the *Manage repository access* modal, which lists your GitHub App installations.
2. Click the *Configure access* button on an installation to change its repository access on GitHub, or click the *Connect a new GitHub account* button to install the GitHub App on a different account.

GitHub will redirect you back to the *Syncing* page once you save your changes.

## Migrate to the GitHub App

The GitHub App integration lets you control which *Git Repositories* CloudCannon can access. If your *Organization* uses the older GitHub integration, the *GitHub* page under *Org Settings* shows a *New GitHub integration available* notice below the page heading, above the tabs.

To migrate to the GitHub App integration:

1. Navigate to the *GitHub* page under the *Files* heading in your *Org Settings*.
2. Make sure you are signed in to GitHub with the same GitHub account shown on the *Authentication* tab.
3. Click the *Upgrade GitHub integration* button.
4. Follow the prompts on GitHub, clicking the *Authorize CloudCannon* button and then the *Install* button to install the GitHub App.

Once the migration is complete, CloudCannon will send a confirmation email with a link to revoke any old authentication in GitHub. You can then delete any webhooks to CloudCannon on your *Git Repositories*.
