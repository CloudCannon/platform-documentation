<comp.Notice info_type="important">
  This feature is only available for Sites [hosted through CloudCannon](/documentation/user-articles/what-is-web-hosting/#hosting-on-cloudcannon). If you host your Site externally, or use CloudCannon in [Headless Mode](/documentation/developer-articles/what-is-headless-mode/), this feature will not work.
</comp.Notice>

Once your [SSL certificate](/documentation/developer-articles/what-is-an-ssl-certificate/) is enabled, users can visit your *Site* on the more secure [HTTPS](/documentation/developer-articles/what-is-an-ssl-certificate/#http-vs-https) URL. We highly recommend redirecting all your HTTP URLs to the more secure HTTPS URLs.

The HTTPS redirect is a setting of the subdomain your *Site* is on, so it applies to every *Site* on that subdomain. Changing it requires the `base-domain:settings:details:write` permission on the *Base Domain*. If you can't change the checkbox, ask someone in your *Organization* who has that permission. Redirect subdomains always redirect HTTP traffic to HTTPS. Your *Site's* [Testing Domain](/documentation/user-articles/what-is-a-testing-domain/) always uses HTTPS, so the *Routing* page only shows this option for *Sites* with a *Custom Domain*.

<comp.Notice info_type="important">
  Turn on the HTTPS redirect once the *HTTPS* section of the subdomain page shows *HTTPS is on*. CloudCannon issues a certificate for each subdomain automatically, or you can upload your own. For more information, please read our documentation on [adding an auto-generated SSL certificate](/documentation/developer-articles/add-an-auto-generated-ssl-certificate/) or [adding a custom SSL certificate](/documentation/developer-articles/add-a-custom-ssl-certificate/).
</comp.Notice>

To redirect visitors to HTTPS:

1. Navigate to the *Routing* page under *Site Settings*.
2. Check the *Redirect all HTTP traffic to HTTPS* checkbox.
3. Click the *Update Routing Details* button.

CloudCannon will now reroute all visitors using the HTTP URL address to the correct HTTPS URL address, for every *Site* on the subdomain.

<comp.DocShot docshot_key="CloudCannon-Documentation-Site-Settings-Routing-HTTPS-Redirect" title="The Routing page" alt="A screenshot of the Routing page shows the Redirect all HTTP traffic to HTTPS checkbox checked." type="screenshot" />

You can also change this setting with the *Redirect http:// visitors to https://* checkbox in the *HTTPS for [Subdomain]* modal on the subdomain page. For more information, please read our documentation on [adding an auto-generated SSL certificate](/documentation/developer-articles/add-an-auto-generated-ssl-certificate/).
