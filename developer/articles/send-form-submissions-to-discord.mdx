You can forward the submissions an <comp.GlossaryTerm term="/user/glossary/i/inbox.yml">Inbox</comp.GlossaryTerm> receives to a Discord channel, using a Discord incoming webhook and a *Discord* target.

Create the webhook in Discord first, because the *Discord webhook URL* field needs its URL. The webhook decides which channel receives your submissions.

To create a Discord webhook:

1. In Discord, open the server that holds the channel that will receive your submissions.
2. Click the *Edit Channel* icon beside that channel to open *Channel Settings*.
3. Open the *Integrations* section, then click the *Webhooks* option.
4. Click the *New Webhook* button, then name the webhook and select the channel it posts to.
5. Click the *Copy Webhook URL* button.

Discord will copy an `/api/webhooks/` URL on `discord.com` to your clipboard.

Now add the target in CloudCannon. Select *Discord* in the *Choose your target type* dropdown and paste the webhook URL into the *Discord webhook URL* field. For the full steps, and for the *Spam protection* and *Links to attached files* options every target carries, please read our documentation on [adding a target to an Inbox](/documentation/developer-articles/add-a-target-to-an-inbox/).

CloudCannon will post each new submission to the channel behind that webhook, as a Discord message.

## Customize the Discord message

Three options under the *Discord* heading in the *Add target* modal control how each message appears.

Turn on the *Send each submission as a rich embed* checkbox to post each submission as an embed, which puts every form field on its own line in a bordered card. Leave the checkbox off to post the submission as plain message content.

Enter a name in the *Username (optional)* field to override the name the webhook posts under, and an image URL in the *Avatar URL (optional)* field to override the avatar shown beside each message.

CloudCannon suppresses mentions in the messages it posts, whichever of these options you choose, so a submission cannot ping a channel or a role. For the payload a Discord webhook accepts, please read the <a href="https://discord.com/developers/docs/resources/webhook" target="_blank" rel="noopener noreferrer">Discord webhook reference</a>.
