<comp.Notice info_type="pricing">
  **Git LFS is available on our <a href="https://cloudcannon.com/pricing/">Standard, Team, or Enterprise Plan</a>.**
</comp.Notice>

<a href="https://git-lfs.com/" target="_blank" rel="noopener noreferrer">Git Large File Storage</a> (Git LFS) stores large files outside your <comp.GlossaryTerm term="/user/glossary/g/git-repository.yml">Git Repository</comp.GlossaryTerm>, while you continue to access them as if they were inside it. Git LFS keeps your *Git Repository* smaller.

You can also keep your *Git Repository* small by storing images and other large files in a <comp.GlossaryTerm term="/user/glossary/d/dam.yml">Digital Asset Manager</comp.GlossaryTerm> (DAM) instead. For more information, please read our documentation on [storing your assets in a DAM](/documentation/developer-articles/introduction-to-assets-and-dams/).

Setting up Git LFS has two parts: installing Git LFS on your computer, and enabling Git LFS for your <comp.GlossaryTerm term="/user/glossary/s/site.yml">Site</comp.GlossaryTerm> in CloudCannon.

## Install Git LFS

To install Git LFS, follow the installation guide on the <a href="https://git-lfs.com/" target="_blank" rel="noopener noreferrer">Git Large File Storage website</a>. Alternatively, you can use the instructions provided by <a href="https://support.atlassian.com/bitbucket-cloud/docs/use-git-lfs-with-bitbucket/" target="_blank" rel="noopener noreferrer">Bitbucket</a>, <a href="https://docs.github.com/en/repositories/working-with-files/managing-large-files/installing-git-large-file-storage" target="_blank" rel="noopener noreferrer">GitHub</a>, or <a href="https://docs.gitlab.com/topics/git/lfs/" target="_blank" rel="noopener noreferrer">GitLab</a>.

<comp.Notice info_type="info">
  You can track your uploads path with Git LFS, so files you upload in CloudCannon are stored with Git LFS. For example, running `git lfs track "uploads/**"` tracks all files inside the `uploads` folder.
</comp.Notice>

## Enable Git LFS for your Site

Before we begin, this article assumes your *Site* already syncs with a *Git Repository*. The *Enable Git LFS* checkbox only appears once your *Site* is connected to a *Git Provider* and has no syncing error.

To enable Git LFS for your *Site*:

1. Navigate to the *Syncing* page under *Site Settings*.
2. Select the *Enable Git LFS* checkbox under the *Additional settings* heading.
3. Click the *Update Settings* button.

CloudCannon will download your Git LFS files the next time your *Site* syncs. While *Enable Git LFS* is off, CloudCannon syncs files tracked by Git LFS as pointer files instead of their contents.
