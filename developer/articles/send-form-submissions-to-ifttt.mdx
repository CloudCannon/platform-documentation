You can forward the submissions an <comp.GlossaryTerm term="/user/glossary/i/inbox.yml">Inbox</comp.GlossaryTerm> receives to an IFTTT applet, using a webhook trigger and an *IFTTT* target.

Create the applet in IFTTT first, because the *Target* field needs its webhook URL.

To create an IFTTT webhook:

1. Sign in to IFTTT, or <a href="https://ifttt.com/join" target="_blank" rel="noopener noreferrer">create an IFTTT account</a>.
2. In the IFTTT console, click the *Create* button to start a new applet.
3. Select the *Webhooks* service, then select *Receive a web request with a JSON payload* as your trigger.
4. Enter an event name, then click the *Create Trigger* button.
5. Add the actions you want, click the *Continue* button, name your applet, then click the *Finish* button.
6. Open the *Webhooks* service from the *My Services* menu, then click the *Settings* button.
7. Open the URL listed under the *Details* heading to find your webhook URL, and replace `{event}` in it with the event name you gave your trigger.

<comp.DocsImage path="assets/external_screenshots/ifttt-com-create.png" alt="A screenshot of the IFTTT console shows the applet creation screen with the Webhooks service selected." title="The IFTTT applet creation screen" type="screenshot" />

Now add the target in CloudCannon. Set the *Type* dropdown to *IFTTT* and paste the webhook URL into the *Target* field. For the full steps, please read our documentation on [adding a target to an Inbox](/documentation/developer-articles/add-a-target-to-an-inbox/).

<comp.DocShot docshot_key="CloudCannon-Documentation-Org-Settings-Forms-Add-Target-IFTTT-Modal" alt="A screenshot of the Add target modal shows the Type dropdown set to IFTTT and an IFTTT webhook URL in the Target field." title="The Add target modal" type="screenshot" />

CloudCannon will trigger your applet with the data from each new submission.
