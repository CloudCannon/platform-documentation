A <comp.GlossaryTerm term="/user/glossary/f/form.yml">Form</comp.GlossaryTerm> can accept file uploads from visitors alongside its other fields, and CloudCannon stores the files with the submission.

Each <comp.GlossaryTerm term="/user/glossary/i/inbox.yml">Inbox</comp.GlossaryTerm> decides whether it takes files at all, using the *Accept file uploads* checkbox on its *Settings* tab. The checkbox is on by default, so a new *Inbox* accepts uploads without any setup. With it turned off, CloudCannon rejects any submission that carries a file and returns an error telling the visitor the form does not accept uploads. Submissions without files keep arriving as normal.

To accept file uploads through a *Form*:

1. Set your form's `enctype` attribute to `multipart/form-data`.
2. Add an input to your form with its `type` attribute set to `file`.

When a visitor submits a file, CloudCannon saves it and replaces it in the submission with a link, and each target decides whether opening that link needs a CloudCannon account or a <comp.GlossaryTerm term="/user/glossary/c/client-sharing.yml">Client Sharing</comp.GlossaryTerm> password. For the options under the *Links to attached files* heading and what each one asks of a recipient, please read our documentation on [adding a target to an Inbox](/documentation/developer-articles/add-a-target-to-an-inbox/).

<comp.CodeBlock language="html" source="upload.html">
```
<form action="/" enctype="multipart/form-data" method="post">
  <input accept="image/png, image/jpeg" id="avatar" name="avatar" type="file">
  <input type="submit" value="Send Message">
</form>
```
</comp.CodeBlock>

## File upload limits

These limits apply to every submission that carries a file:

* Each file must be at most 5 MB.
* At most five files can be submitted at a time.
* Each non-file field must be at most 10 KB.
* At most 100 non-file fields can be submitted at a time.

A submission that exceeds one of these limits is rejected rather than truncated. For the separate limits on how many submissions an *Inbox* accepts, please read our documentation on [how Inbox limits work](/documentation/developer-articles/how-do-inbox-limits-work/).
