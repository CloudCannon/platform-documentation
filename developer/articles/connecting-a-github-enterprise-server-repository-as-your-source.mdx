Connecting a *Git Repository* on your GitHub Enterprise Server to your *Site* allows you to work on your website files locally and sync your changes to CloudCannon. CloudCannon also syncs file changes you make in CloudCannon back to your GitHub Enterprise Server.

<comp.Notice info_type="info">
  To connect a *Git Repository* on GitHub.com instead, please read our documentation on [connecting a Git Repository from GitHub](/documentation/developer-articles/connecting-a-github-repository-as-your-source/).
</comp.Notice>

## Create a GitHub App

Before you configure your GitHub Enterprise Server in CloudCannon, you need to <a href="https://docs.github.com/en/enterprise-server@3.7/developers/apps/building-github-apps/creating-a-github-app" target="_blank" rel="noopener noreferrer">create a new GitHub App</a>. You only need to do this once per server. CloudCannon recommends creating the GitHub App under a GitHub organization.

The GitHub App needs your *Organization's* webhook URL. You can find it in the *Webhook URL* row of the *Configuration details* section on the *GitHub Enterprise Server* page under *Org Settings*.

To create a GitHub App:

1. On your GitHub Enterprise Server instance, open your *Settings*, then select *Developer settings* and *GitHub Apps*.
2. Click the *New GitHub App* button.
3. Enter the following values in the *Register new GitHub App* form:
   * *GitHub App name*: `CloudCannon`
   * *Homepage URL*: `https://app.cloudcannon.com`
   * *Callback URL*: `https://app.cloudcannon.com/github_enterprise_server/authorize`
   * *Setup URL*: `https://app.cloudcannon.com/github_enterprise_server/install`
   * *Redirect on update*: `true`
   * *Webhook URL*: `https://app.cloudcannon.com/hooks/github_enterprise_server/{organization_id}`
   * *Webhook secret*: A random <a href="https://docs.github.com/en/developers/webhooks-and-events/webhooks/securing-your-webhooks#setting-your-secret-token" target="_blank" rel="noopener noreferrer">string with high entropy</a>
4. Set the following values in the *Permissions* section:
   * *Repository permissions*:
     * *Commit statuses*: `Read and Write`
     * *Contents*: `Read and Write`
     * *Metadata*: `Read-only`
     * *Pull requests*: `Read and Write`
   * *User permissions*:
     * *Email addresses*: `Read-only`
5. Check the *Meta* and *Push* checkboxes under *Subscribe to events*.
6. Select the option that best suits your team under *Where can this GitHub App be installed?*.
7. Click the *Create GitHub App* button.

GitHub will create your GitHub App.

## Generate a client secret and private key

After you create your GitHub App, you can generate a client secret and a private key for it. CloudCannon uses these keys, along with your other GitHub App details, to authenticate its requests to your GitHub Enterprise Server. You will need both keys when you configure your GitHub Enterprise Server in CloudCannon.

To generate a client secret and private key:

1. Click the *Generate a new client secret* button in the *General* settings of your GitHub App.
2. Copy the generated client secret and store it in a safe place.
3. Click the *Generate a private key* button in the *General* settings. GitHub will generate a PEM file and download it automatically.
4. Store the downloaded PEM file in a safe place.

You now have the client secret and private key you need to configure your GitHub Enterprise Server in CloudCannon.

## Configure your GitHub Enterprise Server

Before you sync with a *Git Repository* on your GitHub Enterprise Server, you need to configure your instance in CloudCannon. You only need to do this once per *Organization*.

To configure your GitHub Enterprise Server:

1. Navigate to the *GitHub Enterprise Server* page under the *Files* heading in your *Org Settings*.
2. Enter the details for your GitHub Enterprise Server instance:
   * *Endpoint*: The URL of your instance, including `https://` (for example, `https://HOSTNAME`). This field is required.
   * *Authorize URL*: `https://HOSTNAME/login/oauth/authorize`
   * *Token URL*: `https://HOSTNAME/login/oauth/access_token`
   * *GitHub App ID*: The ID that GitHub assigned to your GitHub App.
   * *GitHub App Name*: `CloudCannon`, the name you gave your GitHub App when [creating a GitHub App](#create-a-git-hub-app).
   * *Client ID*: The client ID that GitHub assigned to your GitHub App.
   * *Client Secret*: The client secret you [generated earlier](#generate-a-client-secret-and-private-key).
   * *Webhook Secret*: The random string with high entropy you entered in the *Webhook secret* field of your GitHub App.
   * *Private Key*: The contents of the PEM file you [generated earlier](#generate-a-client-secret-and-private-key).
3. Click the *Configure GitHub Enterprise Server* button.

CloudCannon will save your server details and show the *Authentication*, *Settings*, *Sites*, and *Danger Zone* tabs on the *GitHub Enterprise Server* page. If a field is missing or invalid, CloudCannon will show an error under that field instead.

## Sync with a Git Repository

To sync your *Site* with a *Git Repository* on your GitHub Enterprise Server:

1. Navigate to the *Syncing* page under *Site Settings*.
2. Select the *GitHub Enterprise Server repository* option in the provider dropdown.
3. Click the *Authorize* button.

CloudCannon will redirect you to your GitHub Enterprise Server to authorize CloudCannon.

<comp.DocShot docshot_key="CloudCannon-Documentation-Site-Settings-Syncing-Select-GitHub-Enterprise-Complete" alt="A screenshot of the Syncing page under Site Settings shows the GitHub Enterprise Server repository option selected, with a connected Git Repository and branch." title="The Syncing page with GitHub Enterprise Server connected" type="screenshot"/>

The remaining steps are the same as for a *Git Repository* on GitHub.com. For more information, please read our documentation on [connecting a Git Repository from GitHub](/documentation/developer-articles/connecting-a-github-repository-as-your-source/).

## Disconnect your GitHub Enterprise Server

Disconnecting your GitHub Enterprise Server removes the server and its stored credentials from your *Organization*. CloudCannon keeps the files for any *Sites* that synced with it. You will need to enter your server details again to reconnect.

You must unauthenticate your GitHub Enterprise Server account before you can disconnect the server. For more information, please read our documentation on [unauthenticating your Git Provider](/documentation/developer-articles/authenticate-your-git-provider/#unauthenticate-your-git-provider).

To disconnect your GitHub Enterprise Server:

1. Navigate to the *GitHub Enterprise Server* page under the *Files* heading in your *Org Settings*.
2. Select the *Danger Zone* tab.
3. Click the *Disconnect GitHub Enterprise Server* button.
4. Click the *Confirm* button.

CloudCannon will remove your server details and show the configuration form on the *GitHub Enterprise Server* page.
