You can forward the submissions an <comp.GlossaryTerm term="/user/glossary/i/inbox.yml">Inbox</comp.GlossaryTerm> receives to a Zapier Zap, using a webhook trigger and a *Zapier* target.

Create the trigger in Zapier first, because the *Target* field needs its webhook URL.

To create a Zapier webhook trigger:

1. Sign in to Zapier, or <a href="https://zapier.com/sign-up" target="_blank" rel="noopener noreferrer">create a Zapier account</a>.
2. In the Zapier console, click the *Create Zap* button.
3. Select *Webhooks* as your trigger app and *Catch Hook* as your trigger event.
4. Click the *Continue* button, copy the webhook URL, then click the *Continue* button again.

Zapier now waits for a sample submission to that URL, so leave the Zap unfinished for the moment.

<comp.DocsImage path="assets/external_screenshots/zapier-com-create-zap.png" alt="A screenshot of the Zapier console shows the Create Zap screen with Webhooks selected as the trigger app." title="The Zapier Create Zap screen" type="ui-snippet" />

Now add the target in CloudCannon. Set the *Type* dropdown to *Zapier* and paste the webhook URL into the *Target* field. For the full steps, please read our documentation on [adding a target to an Inbox](/documentation/developer-articles/add-a-target-to-an-inbox/).

<comp.DocShot docshot_key="CloudCannon-Documentation-Org-Settings-Forms-Add-Target-Zapier-Modal" alt="A screenshot of the Add target modal shows the Type dropdown set to Zapier and a Zapier webhook URL in the Target field." title="The Add target modal" type="screenshot" />

Submit to that *Inbox*, then click the *Test Trigger* button in Zapier to pick up the sample. You can now click the *Continue* button and finish setting up your Zap.
