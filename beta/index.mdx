## CloudCannon Beta

CloudCannon releases some features in stages before their full release, so we can collect feedback and make changes. A feature in one of these stages is in either a Private Beta or a Public Beta.

### Private Beta

A <comp.GlossaryTerm term="/user/glossary/p/private-beta.yml">Private Beta</comp.GlossaryTerm> feature is available only to customers who request access. We document Private Beta features in this section of our documentation, with a notice that explains how to request access.

There is no current Private Beta. Keep an eye on our community, your emails, and this page for information about our next Private Beta.

### Public Beta

A <comp.GlossaryTerm term="/user/glossary/p/public-beta.yml">Public Beta</comp.GlossaryTerm> feature is available to everyone, but is still in development, so CloudCannon may change it. We document Public Beta features alongside the rest of our documentation, with a notice that says the feature is in Public Beta, and announce changes to them in our changelog.

The CloudCannon API is in Public Beta. For changes to its endpoints and fields, please read our [API changelog](/documentation/developer-reference/api/changelog/).
