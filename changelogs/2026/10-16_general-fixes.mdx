This release addressed several issues, including those affecting the *Inbox*, *Collection* URLs, and renaming files.

## Fixes

* Fixed an issue where the number of submissions in the *Inbox* toolbar did not update after you deleted submissions.
* Fixed an issue where deleting every submission on the last page of an *Inbox* left you on an empty page instead of moving you to the new last page.
* Fixed an issue where, if a file did not have all the necessary fields in its front matter, data placeholders in the *Collection* URL would persist into the URL value. This affected the URL shown on the file's *Card* and the URL CloudCannon used to open the file in the *Visual Editor*.
* Fixed an issue where renaming a file to the path of a file you had just deleted did not label the change, so it did not appear when you saved.
