This release addressed several issues, including those affecting Inbox permissions, SSL certificates, and file tags.

## Features & Improvements

* Users with the Organization-level *Inbox* permissions can now view, resend, and delete form submissions in any *Inbox* in your *Organization*, without also needing *Inbox* permissions on each *Site*.
* The path of a new file now updates whenever its data is changed, instead of only when the Save modal is open.

## Fixes

* Fixed an issue where a temporary error from our SSL provider during SSL certificate setup was shown as a permanent error. CloudCannon now retries automatically, and only shows an error if the domain is rejected.
* Fixed an issue where SSL certificate setup could request a second certificate for a domain that already had one, leaving SSL stuck on pending.
* Fixed an issue where SSL certificate checks could repeat continuously, delaying other background tasks such as domain and nameserver checks.
* Fixed an issue where a file with unsaved changes could lose its *Edited* tag.
* Fixed an issue where paragraphs with Snippets sometimes rendered with no space between lines in the editing interface.
* Improved error handling around domains that have errored after a DNS changed .
