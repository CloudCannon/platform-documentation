This release added the ability to decline incoming transfer requests and introduced timeouts for requests to external services. It also addressed a wide range of errors across the app, improving reliability in the editing interfaces, analytics, git provider connections, and paginated lists.

## Features & Improvements

* Added the *Decline* button to incoming *Site Transfer* requests, allowing you to reject a request. Declining removes the *Site* from the *Transfer Requests* page under *Org Settings*, and the sender must initiate a new transfer to try again.
* Added *Confirmation Modals* before you can cancel an outgoing *Site Transfer* or decline an incoming one.
* Improved error handling by adding timeouts for requests to external services. Operations that rely on third parties, such as DNS lookups, git provider requests, or email delivery, will now fail with a clear error rather than hang when those services are slow to respond.

## Fixes

* Fixed an issue where, when a resource had changed, accepting a *Site Transfer* would show a generic error rather than explain that the request was out of date.

* Fixed an issue where accepting a transfer request whose resources had changed showed a generic error instead of explaining that the request was out of date.
* Fixed an issue where accepting a transfer request could prompt you to end your trial or increase your billing even when the incoming domains, seats, and shares fit within your plan's included allowance.
* Fixed an issue where the tooltip and arrow on the *Organization* switcher card did not display correctly.
* Fixed several issues that could interrupt the rich text editor, including when exporting certain content to HTML and when navigating away with a link menu open.
* Fixed an issue where replacing content in the *Source Editor* could cause an error when your previous selection fell outside the new content.
* Fixed an issue where a file containing invalid YAML could cause an error instead of showing why it could not be parsed.
* Improved the errors shown when CloudCannon cannot reach your git provider in time or is rate-limited by it, replacing a generic server error with a clear explanation.
* Fixed an issue where the analytics chart could error when you navigated away while it was loading, and improved the message shown when analytics data is temporarily unavailable.
* Fixed an issue where requesting a page beyond the end of a list returned a server error instead of a clear message.
* Fixed an issue where creating a mounted *Site* with a missing or invalid source could cause an error instead of a clear validation message.
* Fixed an issue where the list of pending invitations could fail to load.
* Fixed an issue where the confirmation message did not appear after you deleted a bearer token.
