This release addressed several issues, including those affecting keyboard shortcuts in rich text editors, *File Inputs*, and links to our documentation. It also updated the CloudCannon API.

## Features & Improvements

* Updated the CloudCannon API, which is in Public Beta. For more information, please read our [API changelog](/documentation/developer-reference/api/changelog/).

## Fixes

* Fixed an issue where keyboard shortcuts in a rich text editor applied formatting that the editor's toolbar did not offer. For example, pressing Ctrl+B (or Cmd+B on macOS) made text bold in an editor configured with `bold: false`. Shortcuts now only apply the formatting available in that editor's toolbar.
* Fixed an issue where a *File Input* linking to a page with no source file, such as a tag or pagination page, showed a blank preview. An older *Visual Editor* link to one of these pages also failed to load.
* Fixed an issue where some links from the CloudCannon app to our documentation led to pages or sections that no longer exist.
* Updated dependencies to patch security vulnerabilities.
