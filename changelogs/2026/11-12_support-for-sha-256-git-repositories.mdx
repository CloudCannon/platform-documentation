This release added support for *Git Repositories* that use the SHA-256 object format, and improved performance for the *Details* page under *Org Settings*.

It also addressed several issues, including those affecting *SSL Certificates* for *Custom Domains*, DAMs, Color inputs, and the *Visual Editor*.

## Features & Improvements

* Added support for *Git Repositories* that use the SHA-256 object format, allowing you to sync a *Site* from a repository created with SHA-256 object IDs rather than the default SHA-1.
* Improved performance for the *Details* page under *Org Settings*.
* Updated the CloudCannon API, which is in Public Beta. For more information, please read our [API changelog](/documentation/developer-reference/api/changelog/).

## Fixes

* Fixed an issue where the wildcard *SSL Certificate* for a *Base Domain* on CloudCannon DNS could not renew if its nameservers had not yet changed to CloudCannon. Until the nameservers change, CloudCannon now emails the TXT records needed to renew it, which you can add at your current *DNS Provider*.
* Fixed an issue where a *Subdomain* could show *Issuing* indefinitely if Cloudflare never started issuing its *SSL Certificate*. If Cloudflare has not started after a day, the *Subdomain* now shows an error with a *Retry now* button.
* Fixed an issue where CloudCannon accepted a custom endpoint it could not connect to for an Amazon S3, Cloudflare R2, or DigitalOcean Spaces DAM, such as one with a port or query string, which caused every search of that DAM to fail. The endpoint must now be an HTTPS URL with nothing after the hostname.
* Fixed an issue where, while the search was still loading, choosing a *Base Domain* on the *Custom Domain* page under *Site Settings* would clear your choice and remove the rest of the form.
* Fixed an issue where CloudCannon reported that HTTPS was not working on a *Subdomain* that served visitors a valid *SSL Certificate*, because a second certificate CloudCannon keeps for that *Subdomain* had failed to issue. The *Subdomain* page now shows the certificate your visitors receive, and notes any failure of the second certificate without marking HTTPS as broken.
* Fixed an issue where opening the page for a *Subdomain* from *Site Settings*, right after adding that *Custom Domain* to your *Site*, showed *Subdomain not found* until you refreshed the page.
* Fixed an issue where long domain names stretched the pages and modals for *Custom Domains* beyond the window, causing horizontal scrolling. Long names now wrap, or show in full in a tooltip where they are shortened.
* Fixed an issue where browsing the files in a DAM stopped working after saving *Site Settings*.
* Fixed an issue where clearing a Color input did not save the change. On the *Branding* page under *Org Settings*, clearing a color now resets it to the default brand color.
* Fixed an issue where the message next to a warning icon on a *Snippet* *Card*, such as the warning for an image with no source, did not show in the *Visual Editor*.
* Fixed an issue where the toolbar for rich text controls did not use the same font as the editor.
* Updated dependencies to patch security vulnerabilities.
