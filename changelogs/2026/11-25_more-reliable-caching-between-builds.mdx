title: More reliable caching between builds
date: 2026-11-25T11:20:11+13:00

This release made caching between builds more reliable, so every build of a *Site* can use the files in its *Preserved Paths*, whichever server runs the build. It also added keyboard shortcuts for headings and normal text in rich text editors.

This release addressed several issues, including those affecting rich text editors and reconnecting a *Git Provider*. It also updated the CloudCannon API.

## Features & Improvements

* Improved caching between builds, allowing every build of a *Site* to reuse the files in its *Preserved Paths*, such as `node_modules/`, whichever server runs the build. For more information, please read our documentation on [configuring caching between builds](/documentation/developer-articles/configure-caching-between-builds/).
  * Previously, a build that ran on a different server from the *Site's* previous build, or on a server that had restarted, started without these files and had to recreate them.
  * The build log shows when CloudCannon restores your *Preserved Paths* before a build and when it saves them afterward.
  * When a build is interrupted before it finishes, the next build of that *Site* starts without its *Preserved Paths*, rather than reusing files the interrupted build may have left incomplete.
* Added keyboard shortcuts for headings and normal text to rich text editors, allowing you to change the format of a paragraph without opening the *Format* dropdown in the toolbar. For more information, please read our documentation on [configuring your rich text editors](/documentation/developer-articles/configure-your-rich-text-editors/).
  * On macOS, Option+Cmd+1 to Option+Cmd+6 change the paragraph to a heading of that level, and Option+Cmd+0 changes it to normal text.
  * On Windows and Linux, the same shortcuts use Ctrl+Shift instead of Option+Cmd.
  * Each shortcut only works when the editor's toolbar offers that format.
* Updated the CloudCannon API, which is in Public Beta. For more information, please read our [API changelog](/documentation/developer-reference/api/changelog/).

## Fixes

* Fixed an issue where pressing Tab or Shift+Tab did not indent or unindent list items in a rich text editor that uses the default toolbar.
* Fixed an issue where pasting content into a rich text editor kept formatting the editor's toolbar does not offer, such as bold text in an editor configured with `bold: false`.
* Fixed an issue where *Rich Text Inputs* had no background color of their own, so they showed the color of the panel around them.
* Fixed an issue where a rejected Bitbucket or GitLab connection showed a general error instead of asking you to reconnect your *Git Provider*.
* Fixed an issue where the *Card* for a mounted *Site* on the *Site Mountings* page linked back to the same page instead of to the *Site Dashboard* of the mounted *Site*.
* Fixed an issue where the *Cards* in the *Discard unsaved changes* modal looked selected, even though you cannot select them.
* Fixed an issue where a notice in a modal, such as the *Discard unsaved changes* modal, could overlap the content below it.
* Fixed an issue where a *Card* showed an empty space instead of its icon after its image was removed, or while a replacement image loaded.
* Fixed an issue where the activity feed on the *Home* page stopped working after it refreshed or loaded more activity.
* Fixed an issue where hovering over the avatars of people viewing a file did not show who they were, when the file can't be opened in an editor.
* Fixed an issue where *Date Inputs* caused errors in newer versions of Chrome.
* Fixed an issue where closing a rich text editor that contains a table could cause an error.
* Updated dependencies to patch security vulnerabilities.
