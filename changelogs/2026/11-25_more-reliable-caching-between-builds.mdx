This release made caching between builds more reliable, so every build of a *Site* can use the files in its *Preserved Paths*, whichever server runs the build.

## Features & Improvements

* Improved caching between builds, allowing every build of a *Site* to start with the files its *Preserved Paths* kept from the previous build. Previously, these files could be missing if the build ran on a different server from the last one, or if that server had restarted. For more information, please read our documentation on [configuring caching between builds](/documentation/developer-articles/configure-caching-between-builds/).
  * The build log shows when CloudCannon restores your *Preserved Paths* before a build and when it saves them afterward.
  * When a build is interrupted before it finishes, the next build of that *Site* starts without its *Preserved Paths*, so files left behind by the interrupted build cannot affect it.

## Fixes

* Updated dependencies to patch security vulnerabilities.
