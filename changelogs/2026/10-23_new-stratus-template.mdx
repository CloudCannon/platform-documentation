This release introduced [Stratus](https://cloudcannon.com/templates/stratus), a new documentation starter template, built with Astro and designed for editing in CloudCannon.

It also addressed issues in the Save modal, Group pages, and Subscription settings.

## Features & Improvements

* Stratus became available in the list of templates when you create a new Site.

## Fixes

* Removed the *View As* button for pending Organization Members.
* Fixed an issue where literal values in create paths were used as editable placeholders in the Save modal.
* Fixed an issue where credit was not correctly subtracted from the total cost displayed on the Subscription page.
