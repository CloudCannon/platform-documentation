This release addressed several issues, including those affecting image uploads and webhooks from GitHub.

## Fixes

* Fixed an issue where an input with the `mime_type` option only converted an uploaded image to that file type if CloudCannon also resized the image.
* Fixed an issue where an input did not always check a file against its `accepts_mime_types` option before using it. CloudCannon now rejects any file whose type the input does not accept.
* Fixed an issue where CloudCannon rejected webhooks sent from GitHub's newest IP addresses, which could stop a *Site* syncing commits pushed to GitHub.
* Updated dependencies to patch security vulnerabilities.
