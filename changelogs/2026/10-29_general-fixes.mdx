This release addressed several issues, including those affecting image uploads and webhooks from GitHub.

## Fixes

* Fixed an issue where an image uploaded to an input with the `mime_type` option kept its original file type, rather than converting to the configured type, unless the image also needed resizing.
* Fixed an issue where an upload could succeed even though converting it with the `mime_type` option produced a file type the input doesn't accept. CloudCannon now rejects the upload with an error.
* Fixed an issue where CloudCannon rejected webhooks sent from GitHub's newest IP addresses, which could stop a *Site* syncing commits pushed to GitHub.
* Updated dependencies to patch security vulnerabilities.
