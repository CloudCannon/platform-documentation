This release updated the CloudCannon API.

It also addressed several issues, including those affecting *Select Inputs*, tooltips, the *Partner Program* tiers, and *Site Transfers*.

## Features & Improvements

* Updated the CloudCannon API, which is in Public Beta. For more information, please read our [API changelog](/documentation/developer-reference/api/changelog/).

## Fixes

* Fixed an issue where you could not add a new option to a *Select Input* with `allow_create` enabled when it had only a few options, because no field appeared to type in.
* Fixed an issue where an open dropdown, such as the options list of a *Select Input*, could cover a tooltip, including the tooltip on the clear button.
* Fixed an issue where the *Partner Program* tiers listed the *Experts Directory* listing as a Gold benefit. It is a Silver benefit.
* Fixed an issue where the number of new updates sat too close to the *Updates* label in the *App Sidebar*.
* Fixed an issue where an empty *Sites Browser* did not show a *Site* you had just accepted through a *Site Transfer* until you refreshed the page.
