This release added keyboard shortcuts for headings and normal text in rich text editors, improved the billing and usage emails CloudCannon sends, improved app performance, and updated the CloudCannon API.

It also addressed several issues, including those affecting rich text editors, inviting *Organization Members*, and reconnecting a *Git Provider*.

## Features & Improvements

* Added keyboard shortcuts for headings and normal text to rich text editors, allowing you to change the format of a paragraph without opening the *Format* dropdown in the toolbar. For more information, please read our documentation on [configuring your rich text editors](/documentation/developer-articles/configure-your-rich-text-editors/).
  * On macOS, Option+Cmd+1 to Option+Cmd+6 change the paragraph to a heading of that level, and Option+Cmd+0 changes it to normal text.
  * On Windows and Linux, the same shortcuts use Ctrl+Shift instead of Option+Cmd.
  * Each shortcut only works when the editor's toolbar offers that format.
* Improved the billing and usage emails CloudCannon sends about your *Organization*, allowing you to see what has changed, what it means for your *Sites*, and what to do next.
  * Emails about a *Subscription Plan* change show the previous and current *Subscription Plan*, the cost, and the date of the next invoice.
  * Alerts about *Hosting Bandwidth* and *Build Time* say whether *Overages* are on, and what will happen to your *Sites* or builds when usage reaches 100%.
  * Emails about a failed payment, a *Free Trial* that ended without a payment method, an unpaid invoice, or a canceled subscription explain what has stopped working, how to restore access, and when to contact support.
* Improved performance for the *Flags* page under *Site Settings* and the *Review changes* modal.
* Updated the CloudCannon API, which is in Public Beta. For more information, please read our [API changelog](/documentation/developer-reference/api/changelog/).

## Fixes

* Fixed an issue where members of the *Developers Permission Group*, or of a *Custom Permission Group* with the `group:member:write` permission, could add anyone, including themselves, to a *Permission Group* with permissions they do not hold, such as the *Billing Permission Group*. The same applied to moving a *Site Sharing* member into a *Permission Group*.
* Fixed an issue where inviting someone to an *Organization*, or accepting an invite to one, failed after the *Organization* canceled its subscription.
* Fixed an issue where pressing Tab or Shift+Tab did not indent or unindent list items in a rich text editor that uses the default toolbar.
* Fixed an issue where pasting content into a rich text editor kept formatting the editor's toolbar does not offer, such as bold text in an editor configured with `bold: false`.
* Fixed an issue where *Rich Text Inputs* had no background color of their own, so they showed the color of the panel around them.
* Fixed an issue where closing a rich text editor that contained a table could cause an error.
* Fixed an issue where *Git Provider* screens for a Bitbucket *Site* showed an error, instead of asking you to reconnect, when Bitbucket rejected CloudCannon's access.
* Fixed an issue where comparing changes or creating a *Pull Request* for a *Site* on GitLab showed an unexplained error, rather than asking you to reconnect GitLab, when CloudCannon no longer had an access token for your GitLab account.
* Fixed an issue where a branch created on GitHub could take up to two minutes to appear in CloudCannon, such as in the *Branch* dropdown on the *Syncing* page, for some older *Sites*.
* Fixed an issue where copying a *Site* that had not finished its first sync showed a failed sync on the copy.
* Fixed an issue where the *Card* for a mounted *Site* on the *Site Mountings* page linked back to the same page instead of to the *Site Dashboard* of the mounted *Site*.
* Fixed an issue where the *Cards* in the *Discard unsaved changes* modal looked selected, even though you cannot select them.
* Fixed an issue where, in a narrow window, the text of a warning in a modal, such as the *Discard unsaved changes* modal, could spill out of the bottom of the warning box.
* Fixed an issue where a *Card* showed an empty space instead of its icon after its image was removed, or while a replacement image loaded.
* Fixed an issue where the *App Updates* modal could fail to show its content, and showed every update as unread, after your account details changed while CloudCannon was open.
* Fixed an issue where clicking an avatar in the *Avatar list* to see which files someone has open showed nothing if one of those files had no supported editor.
* Fixed an issue where the *Activity* tab on the *Organization Home* page could hide or misplace activity, or stop working until you reloaded the page, after it refreshed or you loaded more.
* Fixed an issue where, in newer versions of Chrome, an open calendar on a *Date Input* or *Datetime Input* did not stay beside the input when you scrolled.
* Updated dependencies to patch security vulnerabilities.
