This release added more specific filters for accessing the correct data in template strings, and fixed a bug relating to Deploy Previews.

## Features & Improvements

* New template string filters are available, to help in cases where your data shares key names with CloudCannon's fixed placeholders (e.g. "slug"). See [the examples here](/documentation/developer-articles/configure-your-template-strings/) for more information about this.

  * `default_data` operates like the `default` filter, but only checks against your data
  * `default_fixed` operates like the `default` filter, but only checks against CloudCannon's fixed placeholders
  * `if_data` and `if_fixed` operates like the `if` filter, but only check against your data or CloudCannon's fixed placeholders, respectively.
  * `unless_data` and `unless_fixed` operates like the `unless` filter, but only check against your data or CloudCannon's fixed placeholders, respectively.

## Fixes

* Fixed an issue preventing Deploy Previews from working properly on Bitbucket Projects.
* Updated dependencies to patch security vulnerabilities.
