This release introduces a new documentation starter template, called Stratus.

It also addressed issues in the Save modal, Group pages, and Subscription settings.

## Features & Improvements

* A new template, Stratus, is available! It's a documentation site starter built with Astro, designed for editing in CloudCannon.

## Fixes

* Removed the *View As* button for pending Organization Members.
* Fixed an issue where literal values in create paths were used as editable placeholders in the Save modal.
* The cost displayed on the Subscription page now subtracts credit from the total correctly.
